Secure Messaging Flow 10 / 14
Real-Time Communication
Chat that is
authenticated
end-to-end.
Socket.IO WebSocket with JWT-validated identity on every event. No anonymous messages.
1
Donor Opens Chat
Initiates a conversation with a verified charity from their profile or campaign page.
2
JWT Authentication
Server validates token on WebSocket connection. Unauthorised connections are rejected immediately.
3
Messages Persisted
All messages stored in MongoDB with sender ID, timestamp, and conversation ID for audit trail.
4
Block & Report Available
Either party can block the other. Admins can review flagged conversations for policy violations.
5
Real-Time Delivery
Socket.IO emits events to both parties instantly; delivery is confirmed via acknowledgement callbacks.

Security & Privacy 13 / 14
Defence in Depth
Security built at every layer
Authentication
JWT + Firebase OAuth
Signed tokens on every request. Google OAuth via Firebase for social login. Token expiry enforced server-side.
Password Security
bcrypt Hashing
All passwords hashed with bcrypt (salt rounds: 10). Plain-text passwords never stored or transmitted.
Access Control
Role-Based (RBAC)
JWT middleware validates role on every protected route. Donor, charity, and admin routes are strictly separated.
Abuse Prevention
Rate Limiting + Reports
Express rate limiter on auth endpoints. Community report-and-block system with admin enforcement actions.
